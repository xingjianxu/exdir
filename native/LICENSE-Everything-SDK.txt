Everything SDK —— 许可与来源说明
=================================

本目录下的 Everything64.dll 是 **voidtools 官方发布的 Everything SDK** 里的 DLL，
exdir 用它做「基于 Everything 的快速搜索」（见 AGENTS.md 第 4 节“Everything 快速搜索”）。

Everything64.dll 自身只是 **IPC 客户端**：它通过 WM_COPYDATA 跟本机正在运行的
Everything 客户端（窗口类 EVERYTHING_TASKBAR_NOTIFICATION）通信，
**不含**索引引擎、也不读写 Everything 的数据库。
所以随 exdir 分发这个 DLL 并不等于分发 Everything 本体 ——
使用者仍然需要自己安装并运行 Everything（<https://www.voidtools.com/>）。

升级步骤
--------

1. 从上面的官方地址重新下载 Everything-SDK.zip，解出 `dll/Everything64.dll`；
2. 覆盖 `native/x64/Everything64.dll`，**只取 x64** 那一份（x86 / ARM 的不要）；
3. 更新本文件里的大小 / SHA256 / 下载时间，并按需对照新的 `include/Everything.h`
   检查 `Services/Native/EverythingInterop.cs` 里的函数签名与常量；
4. `pwsh -NoProfile -File tools\publish.ps1`（脚本会校验发布目录里有 Everything64.dll）；
5. 跑 `pwsh -NoProfile -File tools\test-search.ps1` 与
   `dotnet run -c Debug --project tools\everything-smoke`。
